# Waleed Korashy Portfolio

Standalone React, Vite, and TypeScript portfolio website shell for Waleed Ahmed Korashy.

This project is intentionally lightweight and static. It is separate from the TaskFlow application repository and is prepared for future deployment on a free static hosting provider.

## Current Scope

- Basic React/Vite/TypeScript project setup
- Typed profile, project, skill, and service data
- Placeholder section components
- Minimal CSS to verify layout and responsiveness
- Basic SEO metadata

The final visual design, project case studies, project screenshots, and polished freelance copy will be added later.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Notes

Portfolio projects are marked as `In Development` until their completed features, visuals, links, and outcomes are confirmed.
